# 25-WritePositioning（产品/行业价值轴）

## 输出目录
`02-drafts/positioning/`

## 必写页面（standard）
- problem.md：行业问题建模 + 本项目的 scope / non-goals
- alternatives.md：常见替代方案 + 何时选你/何时别选你
- differentiators.md：3–5 条差异点（必须落到机制/默认策略/扩展点）
- adoption-paths.md：PoC → 生产 → 规模化 的采用路线

## 规则
- “差异点”必须可映射到 repo 中具体模块或约束（至少给出文件夹/模块名）
- alternatives 必须诚实：写出你不擅长的场景
