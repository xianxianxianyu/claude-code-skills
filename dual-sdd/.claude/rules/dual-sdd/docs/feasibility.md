# Feasibility Schema Rules

> Path-scoped: `**/decisions.md`

## Required Sections
1. Decision Date (ISO8601)
2. Context (background + constraints)
3. Options Considered (min 2)
4. Decision (selected option)
5. Rationale (why this option)
6. Consequences (expected outcomes)
7. Review Date

## Option Requirements
- Name, description, Pros (min 2), Cons (min 1)
- Effort estimate (Low/Medium/High)
- Risk assessment with mitigation

## Cross-Link Requirements
- MUST include `## Source Specification` section
- Link to originating spec.md or proposal.md
