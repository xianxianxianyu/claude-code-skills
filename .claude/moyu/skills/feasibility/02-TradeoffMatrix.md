# TradeoffMatrix

## Purpose
用可比较维度把方案对比清楚，支持决策。

## Suggested dimensions
- correctness risk
- implementation time
- maintenance cost
- compatibility risk
- observability impact
- testability

## Output format
- table or bullet matrix（短、清晰）
